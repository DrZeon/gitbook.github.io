VoiceLib: Core API

VoiceLib — это системный аддон для интеграции Simple Voice Chat с движком Denizen. Библиотека расширяет возможности скриптов, добавляя поддержку нативной обработки звука и проверки состояния голосового чата.

📂 Объект FileTag (file@)

Используется для работы с файловой системой сервера. Позволяет проверять наличие файлов и подготавливать их к декодированию.

  • — возвращает boolean (существует ли файл).
  • — возвращает имя файла.
  • — основная функция. Декодирует MP3 в PCM данные и возвращает объект AudioTag.

🔊 Объект AudioTag (audio@)

Представляет собой аудио-данные, хранящиеся в оперативной памяти в формате PCM (48kHz, Mono).

  • — возвращает общее количество сэмплов в аудио.
  • — инвертирует массив данных (проигрывание задом наперед).
  • — накладывает эффект эха.
  • — смешивает два аудио-потока.

👥 Интеграция с игроками

Плагин расширяет стандартный PlayerTag, добавляя проверку связи:

  • — возвращает true, если у игрока установлен мод и соединение с сервером активно.

🛠 Технические методы (methods.java)

Внутренняя логика обработки звука построена на следующих принципах:

- Частота дискретизации: 48000 Hz
- Формат: short[] (PCM 16-bit)
- Обработка: Mono (автоматическая конвертация при декодировании)

Пример использования в Denizen:

- define sound_file
- if <[sound_file].exists>:
  - define final_audio <[sound_file].decode[100].echo[200]>
  - narrate "Аудио готово к отправке, размер: <[final_audio].sample_count>"
Зависимости: voicechat, Denizen.
