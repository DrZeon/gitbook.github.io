Базовые теги HTML

Ниже приведен список основных тегов, которые необходимы для верстки страниц твоей документации или личного сайта.

Структура текста
  • <h1>...<h6> — Заголовки (h1 — самый важный).
  • <p> — Обычный абзац текста.
  • <br> — Перенос строки (одиночный тег).
  • <hr> — Горизонтальная линия-разделитель.
Форматирование
  • <strong> — Жирный текст (важное выделение).
  • <em> — Курсив.
  • <code> — Код внутри строки.
  • <pre> — Блок предварительно отформатированного текста (сохраняет пробелы).
Списки и Ссылки
  • <ul> — Маркированный список (точками).
  • <ol> — Нумерованный список.
  • <li> — Элемент списка (внутри ul или ol).
  • <a href="url"> — Ссылка. Чтобы открыть в новой вкладке, добавь target="_blank".
Контейнеры (Верстка)
  • <div> — Универсальный блочный элемент (используется для группировки).
  • <span> — Строчный элемент (для выделения части текста внутри строки).
  • <img src="path" alt="desc"> — Изображение.

Пример использования в одном блоке:

<div class="card">
  <h3>Заголовок карточки</h3>
  <p>Текст с <strong>важным</strong> словом.</p>
  <a href="https://github.com">Ссылка на GitHub</a>
</div>
Совет: Всегда закрывай теги (кроме одиночных вроде br и img), чтобы верстка не "поплыла".
